# 차곡차곡 — Windows용 키즈노트 백업과 전자앨범

작은 가족의 추억을 위해 만들었습니다. **by D&S papa**

키즈노트의 알림장, 앨범, 사진과 동영상을 내 컴퓨터에 보관하고 날짜별 전자앨범으로 볼 수 있습니다.

## 다운로드

[차곡차곡 Windows 다운로드 · KidsAlbum-Windows.zip](https://github.com/DRamghi/kidsnote/releases/latest/download/KidsAlbum-Windows.zip)

## 처음 사용하기

1. 위의 다운로드 링크를 누르고 ZIP 파일을 받습니다.
2. 받은 ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택합니다. ZIP 안에서 바로 실행하지 마세요.
3. 압축을 푼 `KidsAlbum` 폴더 안의 `KidsAlbum.exe`를 두 번 눌러 실행합니다. `_internal` 폴더도 함께 있어야 합니다.
4. **키즈노트 로그인**을 누르고, 새로 열린 브라우저에서 평소 쓰는 계정으로 로그인합니다.
5. 앱으로 돌아와 자녀와 받을 자료를 확인하고 **자료 다운로드**를 누릅니다. 기간을 비우면 전체 자료를 받습니다.
6. 다운로드가 끝나면 **전자앨범 열기**를 누릅니다. 알림장·앨범·동영상과 날짜를 골라 기록을 볼 수 있습니다.

Chrome이나 Microsoft Edge가 설치되어 있으면 별도 추가 프로그램을 설치할 필요가 없습니다. 자세한 화면 안내는 ZIP에 들어 있는 `사용설명서.pdf` 또는 `사용설명서.html`을 보세요. 앱의 **사용설명서** 버튼으로도 열 수 있습니다.

## 저장 위치

자료는 `자녀 이름 → 알림장·앨범·동영상 → 날짜` 순서로 나뉘어 저장됩니다. 자녀가 여럿이어도 자료가 한 폴더에 섞이지 않습니다. 이어받을 때는 이전과 같은 저장 위치를 선택하세요. 완료된 파일은 확인 후 건너뛰고 누락된 파일을 다시 받습니다.

여러 아이를 받으려면 한 아이의 작업을 마친 뒤 다음 아이를 선택해 다시 다운로드하세요. 앱이 아이 이름별 폴더로 나눠 보관합니다.

## 도움이 필요할 때

- 브라우저를 찾지 못했다는 안내가 나오면 Chrome 또는 Microsoft Edge를 설치한 뒤 앱을 다시 실행하세요.
- 저장 공간 부족 안내가 나오면 저장 드라이브의 공간을 확보한 뒤 같은 위치로 다시 받으세요.
- 8개 동시 다운로드에서 실패가 반복되거나 멈추면 설정을 4개로 낮추고 다시 받으세요.
- 로그인 만료는 다시 로그인하고, 네트워크 오류는 인터넷 연결을 확인한 뒤 다시 시도하세요.

받은 자료는 자녀와 가족의 개인정보를 포함합니다. 개인 보관 용도로 사용하고, 다른 사람에게 공유하기 전에 내용을 확인하세요.

## 구현

- Tkinter Windows GUI. 별도 임시 브라우저에서 직접 로그인하며 비밀번호/세션을 디스크에 저장하지 않습니다.
- 로그인한 계정의 `/v1/me/info/` 응답에서 자녀와 소속을 확인해 알림장·앨범을 조회합니다. 웹에서 각 메뉴를 미리 열 필요가 없습니다. 기존 목록 응답 감지도 함께 지원합니다. 인증 정보는 메모리에만 유지합니다.
- 사용자가 선택한 자녀와 카테고리만 순차 조회합니다. 실제 페이지 응답의 `next`를 따라가며, 다른 호스트/자녀/종류로 향하는 다음 주소는 거부합니다. 로그인 만료와 오류를 빈 목록으로 처리하지 않습니다.
- 원/반 조건이 있는 요청과 조건 없는 요청을 병합하여 현재/추억 자료를 수집합니다. 권한 밖의 자료를 조회하거나 우회하지 않습니다.
- 사진 유무와 관계없이 글 저장. 게시글 ID 기반 폴더로 날짜 충돌 방지. 미디어 ID 또는 URL 경로 해시로 재실행 중복 방지. URL의 서명 쿼리는 식별에 사용하지 않습니다.
- `.part`에 스트리밍한 뒤 길이를 검증하고 완료 파일로 교체합니다. 재실행 시 크기/SHA-256을 검증합니다. 실패는 완료로 표시하지 않습니다. 중단 시 파일 단위로 복구합니다.
- 사진/글은 `아이/알림장 또는 앨범/날짜/게시글`, 동영상은 `아이/동영상/날짜/게시글`에 보관합니다. 원래 글의 메타데이터로 영상과 연결합니다.
- 단일 `전자앨범.html`에 검색용 메타데이터를 내장합니다. CDN/서버/외부 폰트 없이 `file://`에서 동작합니다. 자료 폴더는 HTML과 함께 보관합니다.
- 카테고리/자녀/월/기간, 전문 검색, 즐겨찾기, 글 상세, 사진 넘기기, 동영상 재생, 인쇄/PDF. 대량 기록은 36개씩 표시하고 이미지는 지연 로딩합니다.
- 전자앨범 상단에서 차곡차곡(기본)·햇살 놀이터·구름 소풍·별빛 책방 테마를 즉시 바꿀 수 있습니다. 팝업에도 적용되며 선택은 현재 브라우저에 저장됩니다. 제목 옆의 곰·토끼 그림도 테마에 맞춰 색이 바뀝니다.
- 서명 URL과 쿠키를 HTML이나 로그로 내보내지 않습니다. API 본문을 HTML로 실행하지 않고 텍스트로 표시합니다. 미디어 쿠키는 CookieJar의 도메인/경로 규칙으로 제한합니다.

## 개발 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

설치된 Edge/Chrome을 사용하므로 Playwright 브라우저 별도 설치는 하지 않습니다.

```powershell
# 기존 JSON 호환 모드
.\.venv\Scripts\python.exe main.py --import-json reports.json --category reports --child-id 123 --child-name 아이이름 --output my-album
# 원본 JS 진입점을 선호하는 경우 같은 엔진으로 연결
node kidsNoteDownloader.js --import-json reports.json --output my-album
# 합성 샘플 앨범
.\.venv\Scripts\python.exe main.py --demo --output demo-album
# 로컬 회귀 테스트 및 실제 Edge의 오프라인 앨범 검증
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_*.py -v
.\.venv\Scripts\python.exe tests\browser_qa.py
# Windows 배포본
.\build.ps1
```

## 검증 한계

실제 사용자 키즈노트 계정은 제공되지 않았습니다. 공개 코드와 합성 데이터로 구현/검증했으며, 현재 로그인 흐름, 해당 계정의 과거 원 자료, 실제 앨범/알림장 응답의 완전성은 로그인 후 확인이 필요합니다. 목록 응답이 첨부를 생략하거나 필드가 변경되면 해당 API에 맞춘 추가 수정이 필요합니다. MP4/MOV/HEIC 등의 재생/표시는 PC 브라우저의 코덱 지원에 따릅니다. HLS 변환/DRM 해제는 지원하지 않습니다. ID가 없는 게시글은 본문/날짜 해시를 사용하므로 본문 수정 시 새 기록으로 인식할 수 있습니다. 만료된 JSON 첨부 주소는 재로그인 조회가 필요합니다.

기존 GUID 기반 다운로드 폴더의 자동 병합은 지원하지 않습니다. 새 앱의 목록.json이 있는 폴더에서 재실행할 때 중복 방지가 적용됩니다. 외부에서 임의로 목록.json을 편집하거나 동일 폴더에 여러 앱을 동시에 실행하는 것은 지원하지 않습니다. 즐겨찾기는 브라우저 localStorage에 저장됩니다. 계정 및 서버의 권한 범위 안에서 개인 보관 용도로 사용하세요.
